# Portfolio data

These two JSON files are a display projection of frozen reports, not new experiments. Each row includes the source JSON pointer. Scan values round the frozen arithmetic means to six decimals; Crowd values round lifecycle means to two decimals. Scan annotations retain the frozen paired-analysis results rather than recomputing a paired estimate from rounded displayed means.

Run `python tools/generate_portfolio_figures.py --check` from the repository root to compare every displayed mean with its source field. Normal rendering reads only these two structured files. Hardware, workload, methodological notes, source commits and claim boundaries travel with the data.
