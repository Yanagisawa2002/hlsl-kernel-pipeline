# Protocol v4: real benchmark native timing integration

Frozen before v4 collection. D3D12 normal standalone / MultiThreaded, Graphics Jobs off, no startup profiler. Formal matrix and merge remain forbidden.

GPU measured frame: T0 -> counter reset + CullAgents -> T1 -> CopyStructureCount + indirect draw -> T2. CPU measured frame: T0 -> T1 -> direct draw -> T2; CPU gpuCullMs is JSON null. Exactly three writes per instrumented frame; ticks/frequency convert to milliseconds with factor 1000. ON also instruments warmup so first-use queries are excluded. OFF allocates/initializes the same backend, but inserts no timestamp callbacks and performs no timestamp polling. Both use the same separate warmup fence and final batch fence.

Attribution is monotonic submission ID (including warmup), slot=(id-1)%32, completed Unity frame fence then readback. No overwrite, duplicate, missing query, blocking slot wait or assumed frame lag. T0<=T1<=T2, positive frequency and valid fence are mandatory. Report measured submitted/resolved counts, invalid count, maximum occupancy, raw triplets and delay distribution. A full pilot requires 1000/1000. Counter-copy belongs to draw; old Recorder and diagnostic datasets are not pooled.

Sequence: final-binary 100k/25% correctness; 96 measured real CPU and GPU frames after 300 warmup as integration availability diagnostics; command-placement capture if practical; overhead control; CPU pilot; GPU pilot; three fresh pairs; then remaining correctness cells. All overhead/pilot runs require three <=5% pre-run NVIDIA samples, zero measured Gen0 GC, v2 pacing and drift gates, complete final fence. Availability/placement diagnostics are not performance evidence and may use an active desktop, retaining load snapshots.

Overhead control uses 100k/.25 seed69501203, 300+1000 frames, two fresh OFF/ON pairs per arm in reversed order (CPU OFF/ON then ON/OFF; GPU OFF/ON then ON/OFF). Evaluate paired batchCompletionMsPerFrame relative shifts. Investigate/STOP if either paired absolute shift exceeds 2%, or the pair conclusions disagree; report both and their range, not a confidence interval. 2% is a conservative engineering threshold, not a statistical theorem; do not subtract overhead. Final-fence observation uncertainty is reported per run and must not exceed 1% of batch cost. No silent retries. Background, capture failure, query/ring or acceptance failures stop dependent performance steps.

Primary architecture measure is batchCompletionMsPerFrame: first measured CPU work to observation of final measured GPU completion, amortized throughput, not per-frame latency. Stage distributions are explanatory. Present-wait metrics remain unavailable unless a reliable supported counter is collected. Three pairs are feasibility only and necessarily have 2:1 first-arm balance. No raw evidence deletion in this task; recommend cleanup only after infrastructure stability.
