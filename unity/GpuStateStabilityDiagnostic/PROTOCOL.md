# GPU-state stability diagnostic: prospective plan

Frozen before launching any diagnostic. DiagnosticOnly=true; eligibleForPerformanceAcceptance=false. No formal V4 policy/source/gate change.

Order: CPU, GPU, GPU, CPU, CPU, GPU; one fresh process per position. Before EACH Player: three existing-format NVIDIA utilization samples one second apart, all <=5%. Any missing/over-threshold sample retains a blocked receipt and stops the sequence. No retries, substitutions or quiet-window loops. No driver/OS/power-policy changes.

Actual arm: same all-agent CPU list/upload/direct draw or GPU cull/append/counter-copy/indirect draw. Same original DLL and timestamp placement/ring, no pipeline-stat queries. Same seed69501203, 100k/.25 original calibration with1000 immutable views. Global frame g uses viewId=g%1000, cycleIndex=g//1000 continuously. Every frame recorded from first real submission, including first300. No excluded warmup or idle between cycles. Existing optional geometry proxies may be joined offline by viewId only.

Duration: stop primarily at30 seconds from first real command-buffer submission; final submission occurs on the first Update reaching that deadline. Safety cap2,000,000 frames; reaching cap before duration is a diagnostic failure. Sample objects are preallocated before workload starts (memory/setup cost is not part of the30-second stream). Deferred timestamp reads retain explicit IDs. A final completion fence drains only after the last workload frame. Serialization occurs after completion; no per-frame I/O or NVML query.

Reuse persistent anonymous NVML sidecar, fixed100ms cadence. It starts before Player and ends after exit. Align samples to CPU submission UTC windows approximately; no assumption of GPU timestamp epoch equivalence. Missing sensor data stays unavailable, never zero. No cross-arm clock equality requirement.

Prospective draw-cost stable transition c-1 -> c: all1000 positive finite view-matched draw ratios exist; median in[0.95,1.05], p10>=0.90 and p90<=1.10. The central80% envelope prevents a narrow median hiding a broad shift; its10% tolerance is twice the5% median tolerance, a diagnostic criterion, not formal acceptance. Report p95 too. GPU range/cull ratios are reported separately, not substituted for draw. Invalid/zero timing invalidates ratio analysis; no samples dropped.

Candidate settling: earliest baseline complete cycle b for which transitions into cycles b+1,b+2,b+3 all satisfy the draw criterion. candidateSettlingCycle=b; candidateSettlingFrame=(b+1)*1000; candidateSettlingTimeSeconds is the boundary after b, measured by next cycle's first submission. Confirmation is available only at the end of b+3. This avoids claiming three cycles are already confirmed at candidate time. Incomplete final cycles are retained but excluded from cycle/transition stability. If later complete transitions fail, record relapse; report a secondary sustained candidate only when all later complete transitions also remain stable. No warmup duration recommendation from an early candidate that subsequently relapses or from an unresolved process.

Clock regime: consecutive median graphics/memory ratios; graphics median change<=10% is descriptive. P-state histogram total variation (half L1 normalized probability difference); never require a single state. These explain, not define, draw stability. Missing cycle telemetry yields unavailable. No frame independence assumption or p-values.

Boundary300: record submission at frame299, insert a passive fence probe there, observe its first passed Update without pausing submissions, and record frame300's submission. warmupDrainMs is the fence-observation upper bound after frame299. postWarmupIdleGapMs is null if frame300 precedes the observation; signed delta is also reported. There is NO enforced idle in this diagnostic. These probes cannot measure the formal V4 blocking transition's exact idle interval; separately inspect original code/historical metadata and state that limit. Record nearest telemetry within150ms and nearby timing at frame300.

Recommendation: only after six valid diagnostics, consider one common fixed wall-clock workload warmup exceeding the worst sustained candidate with explicit margin. Each arm uses its own workload; no synthetic heater/frozen view. If incomplete/blocked, late relapse, insufficient complete cycles, or unresolved within30s, choose C (unresolved), no invented duration/V5. No hardware acceptance, overhead, pilot, feasibility, expanded correctness, formal matrix, merge or extraction in this task.
